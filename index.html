1. 隱私權政策簡介

「任務蒐集助理機器人」（以下簡稱「本機器人」）由誠士資訊股份有限公司（以下簡稱「本服務提供方」）建置及提供。

本政策旨在說明本服務提供方於使用者使用本機器人所提供之任務蒐集、任務辨識、任務建立、任務指派、任務通知及任務管理等服務時，如何蒐集、處理、利用及保護使用者之個人資料及相關資訊，以及使用者依法得行使之權利。

為尊重使用者隱私及保障個人資料安全，本服務提供方將依《個人資料保護法》及其他相關法令規定，於特定目的及必要範圍內蒐集、處理及利用個人資料，並採取適當之安全維護措施。

本服務提供方遵循以下原則：

  • 蒐集個人資料時，於法令要求範圍內告知蒐集目的、資料類別、利用期間、地區、對象及方式等事項。
  • 僅於提供本服務所必要之範圍內蒐集及處理個人資料。
  • 除法令另有規定或為提供本服務所必要外，不任意將個人資料提供予無關之第三人。
  • 依適用法令及本服務目的，於必要期間內保存個人資料。
  • 採取適當之技術及管理措施保護個人資料。
  • 依《個人資料保護法》提供當事人查詢、閱覽、補充、更正、停止處理或利用及刪除等權利。

2. 本機器人蒐集哪些資訊？

為提供任務蒐集及管理服務，本機器人於使用者使用本服務時，將於必要範圍內蒐集及處理下列資料。

LINE 使用者識別資訊

本機器人可能取得 LINE 平台為提供 Bot 服務所傳送之使用者識別資訊，例如：

  • LINE User ID／使用者識別碼
  • LINE 使用者顯示名稱
  • 其他 LINE 平台為提供本機器人服務所提供之必要識別資訊

上述資料主要用於識別使用者、建立任務關聯、進行任務指派、傳送通知及提供相關服務。

LINE 群組識別資訊

當本機器人經群組管理人邀請加入 LINE 群組後，本機器人可能取得與該群組服務相關之資訊，例如：

  • LINE 群組識別資訊（Group ID）
  • 群組相關服務識別資訊
  • 本機器人加入、退出群組之相關紀錄

上述資訊用於識別本機器人所服務之群組，並確保任務資料歸屬於正確之群組。

群組訊息內容

為提供任務蒐集及任務辨識功能，本機器人將接收 LINE 平台傳送之相關訊息事件。

本機器人可能處理：

  • 使用者於群組中傳送之與任務服務相關訊息
  • 任務描述
  • 任務內容
  • 任務建立者
  • 任務負責人
  • 任務期限
  • 任務狀態
  • 與任務建立、指派、更新及完成相關之訊息

使用者應注意，當本機器人加入 LINE 群組後，群組成員於該群組所傳送之訊息，可能因本機器人服務功能而被接收及處理。

因此，請避免於群組中傳送與本服務無關且涉及他人隱私之敏感個人資料。

4. 本機器人如何收集你的資料？

本機器人可能於您使用本服務的過程中，依服務功能及提供目的，蒐集您主動提供或系統產生的相關資料。

當您：

  • 使用本機器人與系統進行對話或傳送訊息。
  • 於 LINE 群組或與本機器人進行互動時提供任務、工作內容或其他相關資訊。
  • 使用本機器人之任務管理、任務指派、任務查詢或其他相關功能。
  • 使用本機器人所提供之 LIFF 網頁或其他相關服務。
  • 聯繫客服、反映問題、提供意見或回饋時。

本服務可能蒐集下列資料：

  • LINE 使用者識別資訊，例如 LINE User ID。
  • 使用者於本服務中提供之名稱或暱稱。
  • 使用者所傳送的訊息內容，以及其中所包含的任務資訊。
  • 任務相關資料，例如任務名稱、任務內容、負責人、建立時間、截止時間、任務狀態等。
  • 使用本服務所產生的操作紀錄及系統紀錄。
  • 使用 LIFF 或網頁服務時所產生之必要技術資訊，例如瀏覽器、裝置及連線相關資訊。

本服務原則上僅於提供任務蒐集、任務管理、任務指派、任務查詢及相關服務所必要的範圍內蒐集及使用個人資料。

我們不會要求您提供與本服務目的無關的個人資料；如您於訊息內容中主動提供其他個人資料，該等資料可能隨訊息內容一併被系統處理。

5. 本機器人如何儲存您的資料？

本服務提供方會採取適當的技術及管理措施，安全儲存您使用「任務蒐集助理」所產生及提供的資料，以避免個人資料遭未經授權之存取、竄改、洩漏、遺失或其他侵害。

依本服務實際使用之系統架構，資料可能儲存於本服務提供方或其所使用之雲端服務、資料庫及相關資訊系統中。實際資料儲存位置將依系統架構及服務提供方式而定。

我們會依服務提供及資料處理所需，採取適當的資訊安全措施，包括但不限於：

資料安全與保護

我們依據服務需求及資訊安全風險，採取適當的技術及組織措施，以保護本服務所蒐集及處理的個人資料，防止未經授權的存取、使用、揭露、修改、毀損或遺失。

安全傳輸

本服務於使用者、應用程式及相關服務系統之間傳輸資料時，原則上採用 HTTPS／TLS 等安全傳輸機制，以降低資料於傳輸過程中遭攔截或竄改之風險。

存取控制與最低權限

本服務依最小權限原則限制個人資料及系統資料的存取權限，僅授權予因執行業務、維護系統或提供服務而有必要之人員或系統使用。

相關存取權限將依職務及實際業務需求進行控管，並於必要時透過帳號驗證、權限管理及系統紀錄等方式進行管理。

任務資料之使用限制

透過 LINE、LIFF 或其他本服務介面取得的訊息及任務資料，主要用於提供任務蒐集、任務辨識、任務建立、任務指派、任務查詢、任務狀態管理及其他使用者明確使用的相關功能。

如系統使用人工智慧或其他自動化分析技術處理訊息內容，原則上僅於提供上述服務所必要的範圍內進行處理。

資料保留與刪除

本服務會依提供服務所需之期間保存相關資料。當資料已無繼續保存之必要，或依適用法令及使用者依法提出刪除等要求時，將依相關程序刪除、停止使用或採取適當的匿名化處理。

但依法令規定或因處理爭議、履行契約、維護系統安全等必要情形，可能於必要期間內繼續保存相關資料。

安全監控與事件應變

我們會依服務運作及資訊安全需求，採取適當的系統監控及安全防護措施，並於發生個人資料遭未經授權存取、洩漏或其他資訊安全事件時，依適用法令及相關程序進行處理，並於法令要求之情形下通知相關當事人或主管機關。

人員保密義務

凡因業務需要而接觸個人資料之本服務相關人員，均應依其職務及相關規範負有保密義務。違反相關保密義務者，將依適用法令及本服務提供方之內部規範處理。

12. 是否將個人資料提供予第三方？

除下列情形外，本服務提供方不會任意提供、交換、出租或出售使用者之個人資料予無關之第三人：

  • 經使用者同意。
  • 法律另有規定。
  • 主管機關或司法機關依法要求。
  • 為提供本服務所必要，且於適當之資料保護及契約約束下，由受委託之服務人員進行必要之資料處理。

本服務目前採地端部署架構，相關任務資料及 AI 分析資料原則上於本服務地端環境處理。

使用者於 LINE 群組中所傳送之訊息，可能包含使用者本人或其他群組成員之個人資料。

當使用者於群組中傳送訊息時，該訊息可能被其他群組成員閱覽，並可能因本機器人之服務功能而被接收及處理。

因此，使用者於使用本機器人時，應避免傳送不必要之敏感個人資料或其他不應於群組公開之資訊。

14. 個人資料當事人之權利

依《個人資料保護法》相關規定，當事人就本服務所蒐集之個人資料，得依法行使下列權利：

  • 查詢或請求閱覽。
  • 請求製給複製本。
  • 請求補充或更正。
  • 請求停止蒐集。
  • 請求停止處理。
  • 請求停止利用。
  • 請求刪除。

當事人如欲行使上述權利，應透過本服務提供方所提供之聯絡方式提出申請，並於必要時提供足以確認本人身分之資訊。

惟如依法有保存義務、因執行業務所必要，或其他法律規定之正當事由者，本服務提供方得依法不予刪除或停止處理、利用。

使用者得自行決定是否使用本機器人服務。

惟部分資料為提供本機器人核心功能所必要，例如使用者識別資訊、群組識別資訊及與任務服務相關之訊息。
